# Lucibello Website

A polished ecommerce-style frontend built with **Next.js** and **React**, focused on product presentation, motion, reusable UI components and responsive design.

## Features

- Product-focused landing page
- Interactive hero carousel
- Dynamic theme transitions based on the active product
- Reusable product-card and product-section components
- Responsive navigation and announcement bar
- Component-scoped CSS modules
- Clean App Router structure

## Tech stack

- Next.js 14
- React 18
- JavaScript
- CSS Modules

## Project structure

```text
src/
  app/
    page.js
    layout.js
    globals.css
  components/
    AnnouncementBar
    Navbar
    HeroCarousel
    ProductCard
    ProductsSection
  data/
    products.js
```

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```
